# Student Academic Management Knowledge Repository

## Overview

This repository contains the structured knowledge of a Student Academic Management System. The knowledge was developed from the knowledge base created in Experiment 1 and organized into separate JSON files.

## Repository Contents

* `student_knowledge.json` – Contains student information such as student ID, name, attendance, and CGPA.
* `subject_faculty_knowledge.json` – Contains information about subjects, faculty, and their relationships.
* `examination_result_knowledge.json` – Contains examination eligibility rules and student subject results.
* `academic_rules.json` – Contains rules related to attendance, CGPA, and subject performance.
* `relationships.json` – Contains the relationships between students, subjects, faculty, examinations, results, and assignments.

## Purpose

The purpose of this repository is to organize, maintain, share, and reuse the knowledge of the Student Academic Management System using structured JSON files and GitHub.

## Tools Used

* JSON – Structured representation of knowledge
* Git – Version control
* GitHub – Cloud-based repository and public access
